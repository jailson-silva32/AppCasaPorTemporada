AppCasaPorTemporada 🏡
O AppCasaPorTemporada é um aplicativo mobile desenvolvido em Java com FireBase, focado no gerenciamento e reserva de casas para temporada. O projeto visa proporcionar uma experiência intuitiva e eficiente para usuários que desejam encontrar e alugar imóveis de forma prática.

🔹 Tecnologias Utilizadas
Java– Para a construção da interface mobile responsiva e fluida.
TypeScript – Para maior segurança e melhor organização do código.
Styled Components – Para estilização dinâmica e modularizada.
Context API – Para gerenciamento de estado global da aplicação.
React Navigation – Para navegação entre telas de forma eficiente.
Firebase – Para autenticação de usuários e armazenamento de dados em tempo real.

📌 Funcionalidades
Listagem de imóveis disponíveis para locação.
Detalhes de cada propriedade com imagens e informações relevantes.
Sistema de reserva para locação por temporada.
Interface moderna e intuitiva para melhor experiência do usuário.
